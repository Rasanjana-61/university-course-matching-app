# CAREER MATCH launcher assets

The source is the existing welcome-screen logo in
`src/screens/WelcomeScreen.tsx`: `<Ionicons name="school" size={48}
color="#FFFFFF" />` on `Brand.primary` (`#1A56DB`) from
`src/constants/theme.ts`.

`career-match-school.svg` contains the exact vector outline extracted from the
installed `@expo/vector-icons` Ionicons `school` glyph (code point 62812,
U+F55C), using its bundled
`build/vendor/react-native-vector-icons/Fonts/Ionicons.ttf` and
`glyphmaps/Ionicons.json`. It is not traced from a screenshot or generated by AI.
Ionicons is MIT licensed: https://github.com/ionic-team/ionicons/blob/main/LICENSE.

All launcher PNGs are 1024 by 1024 pixels:

- `career-match-icon.png`: white cap on an opaque `#1A56DB` background, with
  the cap's longest dimension at 512px.
- `career-match-adaptive-foreground.png`: white cap on transparency, with its
  longest dimension at 480px, centered in both directions.
- `career-match-monochrome.png`: the same cap and transparent padding for
  Android themed icons; the system supplies the themed foreground color.

The adaptive and monochrome artwork fits entirely inside the centered
66/108 safe circle (radius about 313px on a 1024px canvas). The adaptive blue
background comes from `android.adaptiveIcon.backgroundColor` in `app.json`.
No old Expo foreground, background, or monochrome image is referenced by the
Android launcher configuration.

For rasterization, scale the SVG's vector group around canvas center (512,512)
so its longest dimension is 512px for the opaque icon or 480px for the
transparent assets. Use the same path for all variants.
